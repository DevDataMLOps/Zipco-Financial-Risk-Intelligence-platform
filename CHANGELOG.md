- Added continuous repository validation for contracts, links, required artifacts, manifests, file size, and credential patterns.

### Declared boundaries

- The project uses synthetic data and does not contain real customer records.
- The risk engine is an analyst-prioritization demonstration, not an automated decision model.
- Native Kinesis and Firehose deployment is not claimed; the verified path is the Free-plan Lambda/S3 variant.
- AWS evidence records historical successful runs and does not continuously assert live resource state.
